# 手机打印助手（Print Server）

> 让手机浏览器直接驱动电脑上的 USB 打印机。
> 手机连同一个 WiFi → 打开一个网址 → 选文件 → 电脑这边自动排版并静默出纸。
> 不用在电脑上点任何"下一步"，也不用把文件传来传去。

最初是为了解决一个具体问题：**手机同 WiFi 找不到电脑上的 EPSON L360 打印机**。
L360 是 USB 打印机，没有网络打印能力，Windows 的共享打印又经常在手机端搜不到。
于是干脆反过来——在电脑上起一个极轻量的 HTTP 服务，把"打印"这个动作做成手机网页上的一个按钮。

---

## 它能做什么

| 功能 | 说明 |
| --- | --- |
| 手机上传打印 | 图片 / PDF / Word / Excel / PPT / 纯文本，浏览器里选完就打 |
| 随手记 | 手机上现打一段字，选字号直接出纸（便签、备忘） |
| 截图排版 | 多张截图拼到一页上，可调位置、缩放、每页张数 |
| 微信自助打印 | 直接列出电脑版微信收到的**文件**和**图片**，手机上勾选即打 |
| 原格式直印 | Office 文档可走 COM 原生打印，完全保留原文件的页边距、分页 |
| 重排放大 | 遇到 PDF/图片自带白边时，先剥掉白边再等比放大到设定的页边距 |
| 多打印机适配 | 自动识别真实打印机（虚拟 PDF 打印机被自动排除），并按驱动能力过滤纸张 |
| 便携版 | 打包成一个 80MB 的绿色文件夹，别的电脑免装 Python、双击即用 |

## 快速开始

### 方式 A：便携版（推荐给"只想用起来"的人）

1. 到 [Releases](../../releases) 下载 `手机打印助手-v1.0-便携版.zip`
2. 解压到任意位置，**双击 `启动打印助手.bat`**
3. 弹出的黑色窗口里会显示一个网址，如 `http://192.168.x.x:8760`
4. 手机连同一个 WiFi，浏览器打开这个网址

不需要装 Python、不需要联网、不写注册表。换台电脑把整个文件夹拷过去照样能跑。

### 方式 B：从源码跑（开发者）

```bash
pip install -r requirements.txt
python server.py
```

服务默认监听 `0.0.0.0:8760`，被占用会自动往后顺延到 8765。启动日志会打印局域网 IP。
想让它开机自启 + 自动放行防火墙，用管理员权限跑一次 `首次安装并启动.bat`。

> 第一次跑建议先执行 `python selftest.py`：它不消耗纸张，只在内存里把整条打印链路走一遍。

## 用起来是什么流程

```
① 电脑上跑起来（bat 或 python server.py）
        ↓
② 手机浏览器打开 http://<电脑IP>:8760
        ↓
③ 三种来源任选：本地上传 / 微信聊天文件 / 微信聊天图片
        ↓
④ 选纸张（A4、A5、B5、A6、Letter、4R…）、方向、质量、页边距
        ↓
⑤ 预览 → 点打印 → 电脑这边的打印机出纸
```

手机上看到的就是一个网页，不用装 App，iOS / Android / 平板都行。

## 支持的格式与纸张

- **输入格式**：jpg / png / webp / heic / bmp / gif、pdf、doc(x) / xls(x) / ppt(x)、txt / md
- **纸张**：A4、A5、B5、A6、Letter、Legal、4R(6寸)、5R(7寸)
  实际能选哪些，由**打印机驱动上报的能力**决定，不支持的选项是灰的
- **质量**：草稿 200dpi / 标准 300dpi / 精细 360dpi（贴着 L360 原生分辨率）

## 微信那部分，先说清楚

这不是破解微信，也不是读聊天数据库：

- **文件**：微信 PC 端会把聊天里收发的文件原样落在本地磁盘上（带真实文件名），
  程序只读这个目录，**复制**一份到自己的工作区，绝不移动、修改、删除微信原始数据。
- **图片**：聊天里直接发的原图是 **AES 加密存储的 `.dat`**，密钥只在微信进程内存里，
  离线解不开，本项目**不做也不打算做**这件事。
  能取到的是微信自己另外存的明文缓存（缩略图、收藏高清图、迁移图），
  每张图都会标注清晰度评级和建议纸张，避免打出一张糊的。

细节见 [docs/03-微信文件与图片.md](docs/03-微信文件与图片.md)。

## 安全与隐私

- 全程**不联网上传**任何内容，所有数据只在本机和局域网内流转。
- 服务只监听局域网，防火墙规则默认限制 `remoteip=localsubnet`。
- 只读微信自己落盘的缓存，不注入微信进程、不改微信文件。
- 上传的作业存在 `runtime/jobs/`，可随时删除，`dist/` 和 `runtime/` 都不进 Git。

## 目录结构

```
printserver/
├── server.py          HTTP 服务与全部 API（调度中枢）
├── printer_core.py    打印机枚举、纸张能力、GDI 打印
├── renderer.py        渲染：PDF / Office / 图片 / 文本 → 位图
├── layout.py          多图排版（截图拼版）
├── native.py          Office COM 原格式直印
├── office.py          Office COM 小工具
├── wechat.py          微信本地数据扫描（文件 + 图片）
├── selftest.py        不耗材的自检脚本
├── setup.py           防火墙放行 + 开机自启
├── build_portable.py  打包便携版
├── web/               手机端页面（index.html / editor.js / editor.css）
├── tools/             辅助脚本（下载嵌入式 Python 等）
├── docs/              文档
└── dist/              打包产物（不进 Git）
```

## 已知限制

- 只支持 **Windows**（依赖 pywin32 / GDI / Office COM）。
- Office 原格式直印需要本机装有 Word / Excel / PowerPoint。
- 微信聊天原图离线不可解，只能用明文缓存版本（见上文）。
- 打印走的是本机打印队列，电脑必须开机且打印机在线。
