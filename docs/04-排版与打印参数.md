# 04 · 排版与打印参数

这一章解决三个高频疑问：**边距怎么统一**、**能不能按原文件等比例放大**、**排版方式会不会和边距冲突**。

## 先说清楚一件事：两种打印通道

| 通道 | 走的路径 | 边距谁说了算 |
| --- | --- | --- |
| **位图通道**（默认） | 文件 → 渲染成位图 → 按你设的边距摆到纸上 | 你设的边距 |
| **原格式直印**（Office） | 直接调 Word/Excel/PPT 的 `PrintOut` | **文档自己** |

选哪个，决定了后面所有参数怎么理解。

## 1. 位图通道的页边距

页面上的选项：

| 选项 | 效果 |
| --- | --- |
| 原生 | 跟随文档自身的页边距（PDF 的话就是它内嵌的 CropBox） |
| 适中 | 四周留约 12mm，最常用 |
| 窄 | 约 6mm，省纸 |
| 无 | 满幅出血，照片用这个 |
| 自定义 | 自己填毫米数 |

工作方式是：先按纸张和 dpi 算出一个"画布"，再把内容缩放摆进**去掉边距后的可用区域**。

### 曾经踩过的坑：边距套边距

PDF 自己带 2cm 页边距，渲染成位图后这 2cm 白边就成了图像的一部分；
这时再按"适中"缩到边距框里，白边又被缩了一次 —— 内容整整小了一圈，边距看起来是双倍的。

修法是 **「重排放大」（reflow）**：

```
原始页 → 检测内容边界（content bbox）→ 剥掉四周白边 → 等比放大填满设定的边距框
```

效果：一份扫描版试卷，用 reflow 之后文字能顶到设定的 12mm 边距上，不再缩在中间一小块。
实测打过 4 页试卷，字明显变大、边距整齐。

**什么时候开 reflow：**

- ✅ 扫描件、截图、带大片白边的 PDF
- ✅ 想让小图撑满纸
- ❌ 本来就是满幅的照片（没有白边可剥，开了也没变化）
- ❌ 需要严格保持原始排版比例的场景（用"原格式直印"）

## 2. 原格式直印（Office）

Word/Excel/PPT 勾选**原格式直印**后，走的是 `native.py` 的 COM 通道：

```python
word.Documents.Open(path)
doc.PrintOut(...)   # 由 Word 自己决定纸张、边距、分页
```

这样打印出来和你在电脑上按 Ctrl+P 一模一样 —— 边距、页眉页脚、分页位置全部保留，
不会被二次缩放。代价是：

- 电脑上必须装对应的 Office（WPS 的 COM 接口不完全兼容）
- 打印过程中会短暂唤起 Office 进程（已做串行锁，不会并发打架）
- 页面的"边距"选项此时不起作用（因为边距归文档管）

**所以"排版方式会不会和边距冲突"这个问题，答案是：**
走原格式直印时，页面上设的边距会被忽略（这是对的，原文件说了算）；
走位图通道时，你设的边距才生效。两条路互斥，不存在叠加。

## 3. 等比例放大

这就是 reflow 干的事，但要注意一点：**放大不会凭空增加清晰度**。

程序会按图片实际像素算出它在目标纸张上能达到的 dpi，并给出清晰度提示：

```
dpi = min(图宽 / 纸宽英寸, 图高 / 纸高英寸)
```

例如 4032×3024 的照片打到 A4（8.27×11.69 英寸）：

```
宽方向 4032 / 8.27 ≈ 487
高方向 3024 / 11.69 ≈ 259
取小 = 259 dpi  ← 高方向是瓶颈
```

所以那张照片放 A4 满幅实际只有约 259dpi，够用但不是原生 360dpi。
而一张 800×600 的缩略图放 A4 只有 68dpi，必然糊 —— 这时应该选 A6 或 4R。

> 早先这里把 min/max 写反过，导致 dpi 被高估、糊图被标成"清晰"。现在已修正，
> 微信图片列表里的清晰度标签就是按这个算的。

## 4. 纸张、方向、质量

- **纸张**：A4、A5、B5、A6、Letter、Legal、4R(6寸)、5R(7寸)。
  注意：能选哪些取决于**打印机驱动上报的能力**，不支持的选项是灰的。
  万一前端传了个驱动不支持的纸张，后端会降级为 A4 兜底而不是报错。
- **方向**：纵向 / 横向
- **质量**：草稿 200dpi / 标准 300dpi / 精细 360dpi
  L360 原生 360dpi，贴着原生渲染最清晰；但 360dpi 下 A4 单页位图约 30MB，慢一些。

## 5. 多图排版（截图拼版）

`layout.py` 负责。手机上传多张截图后，可以在编辑器里：

- 拖动位置、缩放
- 选择每页放几张（1/2/4/6/9 宫格）
- 长图自动分页、去白边、裁状态栏、给单张图加标题
- 调整顺序

编辑器的画布比例是**从后端拿的真实像素尺寸**（`/api/canvas`），
不是前端猜的，所以预览和出纸一致。

### 排完之后的流程：下一步 → 打印选项

底部按钮是**「下一步」**，不是「打印」。排版完不会直接出纸：

```
排完版面
   │
   ▼  点「下一步」
打印选项页 ── 打印机 / 纸张 / 方向 / 颜色 / 清晰度 / 份数
   │
   ├─ 点「看成品效果」→ POST /api/compose-preview → 出当前页预览图
   │
   ├─ 点「回去改」  → 回到编辑器继续摆
   │
   └─ 点「打 印」   → POST /api/compose → 真的出纸
```

为什么要多这一步：以前点「打印」是直接 `/api/compose` 一把梭，
纸出来才发现纸型选错、忘了转横向、打成黑白。

两个细节：

- **改纸张 / 方向会重新拉画布并重排**。因为坐标是页面归一化比例，
  不重排的话「按 A4 摆的版面」打到别的纸上位置会歪。
- **预览用的是打印同一个 `LY.compose_pages`**，不是另一套近似算法，
  所以屏幕上这张就是把要出来的那页。

## 6. 常见组合建议

| 想打什么 | 纸张 | 边距 | 其他 |
| --- | --- | --- | --- |
| 合同/论文 | A4 | 原格式直印 | 走 Office 通道 |
| 扫描试卷 | A4 | 适中 + 重排放大 | 字会明显变大 |
| 手机照片 | 4R | 无 | 满幅出血 |
| 多张截图 | A4 | 适中 | 用拼版 2/4 宫格 |
| 便签随手记 | A5/A6 | 适中 | 文本通道 |
| 微信缓存图 | 看清晰度标签 | 适中 | 偏软的就别放大尺寸 |
