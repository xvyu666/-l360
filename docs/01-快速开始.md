# 01 · 快速开始（10 分钟跑起来）

## 0. 先确认三件事

- [ ] 电脑是 **Windows**，打印机驱动已经装好，并且本地能正常打印（先在电脑上随便打一张测试页确认）
- [ ] 手机和电脑连的是**同一个 WiFi**（不是手机流量，也不是电脑有线 + 手机无线的不同网段）
- [ ] 电脑上没装 360/火绒之类会拦截局域网访问的杀软（装了的话后面放行一下）

> 打印机不需要支持网络打印。这正是本项目的意义：L360 这种纯 USB 打印机也能被手机驱动。

## 1. 电脑上启动服务

### 方式 A：便携版（不用装 Python）

1. 从 Release 下载 `手机打印助手-v1.0-便携版.zip` 并解压
2. 双击 **`启动打印助手.bat`**
3. 保留弹出的黑色窗口（关掉窗口 = 关掉服务）

窗口里会出现：

```
   手机打印服务已启动
   手机连同一个 WiFi 后，浏览器打开：

       http://192.168.x.x:8760

   打印机：EPSON L360 Series
   按 Ctrl+C 停止
```

### 方式 B：源码运行

```bash
pip install -r requirements.txt
python server.py
```

第一次跑之前建议先自检一遍（不费纸）：

```bash
python selftest.py
```

看到 `=== 自检通过 ===` 就说明打印机枚举、纸张能力、渲染链路都正常。

## 2. 手机打开网页

手机浏览器输入上面那个地址，例如 `http://192.168.x.x:8760`。

建议加到手机主屏（浏览器菜单里的"添加到主屏幕"），以后一点就开。

### 电脑上也想一点就开

```bash
python tools/make_shortcuts.py
```

桌面会出现「**手机打印助手**」。双击它就三件事连着做完：
服务没起 → 帮你起 → 打开浏览器。走的是 `127.0.0.1`，
所以 192.168 那个地址怎么变都不影响。

```bash
python tools/make_shortcuts.py --verify   # 只看一眼快捷方式指向哪
python tools/make_shortcuts.py --remove   # 删掉
```

> 用的是便携版的话，`tools/` 不在解压目录里。直接右键
> `启动打印助手.bat` → 发送到 → 桌面快捷方式，一样的效果。

## 3. 打第一张：先打测试页

别急着打正式文件。页面上点 **「打印测试页」**，确认：

- 打印机有反应、出纸
- 纸上是"手机打印联调测试" + 一个方框 + 时间

测试页能出，说明整条链路（网络 → 服务 → GDI 打印）都是通的。

## 4. 正式打印

三种来源任选：

| 来源 | 怎么用 |
| --- | --- |
| **本地上传** | 点上传，从手机相册 / 文件里选图片、PDF、Word 等 |
| **微信文件** | 切到「微信」→「文件」，列出电脑版微信收到的文件（需电脑微信保持登录） |
| **微信图片** | 切到「微信」→「图片」，列出本地明文缓存的图，带清晰度标签 |

选好之后：

1. 选**纸张**（A4 / A5 / 4R…）和**方向**
2. 选**质量**（标准 300dpi 一般就够）
3. 选**页边距**（默认"适中"；想完全保留原文件边距就选"原格式直印"，见 [04](04-排版与打印参数.md)）
4. 点**预览**看一眼，确认没问题
5. 点**打印**

## 5. 让电脑 IP 别变（重要）

家用路由器默认 DHCP，电脑 IP 可能隔几天就变一次，手机上存的书签就失效了。

解决办法二选一：

- **路由器里绑定**：在路由器后台把这台电脑的 MAC 和某个 IP 绑定（推荐，一劳永逸）
- **电脑设静态 IP**：控制面板 → 网络适配器 → TCP/IPv4 → 手动指定

## 6. 关掉服务

- 便携版：关掉那个黑色窗口
- 源码版：Ctrl+C，或者双击 `停止打印服务.bat`
