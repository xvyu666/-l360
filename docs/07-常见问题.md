# 07 · 常见问题

## 手机打不开那个网址

按顺序排查：

1. **电脑上的服务还在跑吗？** 黑窗口被关掉 = 服务没了。重新双击 bat。
2. **IP 变了没？** 路由器 DHCP 会换 IP。电脑上重开服务，看窗口里显示的新地址。
   长期方案：路由器里把 MAC 和 IP 绑定（见 [01](01-快速开始.md) 第 5 节）。
3. **手机和电脑在同一网段吗？** 电脑插网线、手机连 WiFi，有些路由器会把它们隔离开
   （"AP 隔离"/"访客网络"）。关掉访客网络试试。
4. **防火墙拦了。** 用管理员权限跑一次 `首次安装并启动.bat`，它会加一条
   仅限局域网的放行规则。手动加：

   ```bash
   netsh advfirewall firewall add rule name="手机打印服务" dir=in action=allow protocol=TCP localport=8760-8765 remoteip=localsubnet
   ```
5. **杀软。** 360 / 火绒 / 卡巴斯基可能拦局域网入站，加白名单。

## 页面上找不到打印机 / 打印机列表是空的

- 电脑上的打印机驱动装好了吗？先在电脑上打一张测试页确认。
- 程序只列**真实打印机**，虚拟的（Microsoft Print to PDF、XPS Writer、WPS 导出 PDF、Fax…）
  会被自动排除。判据是**端口**：`USB001`/`LPT`/`COM`/`IP_`/`WSD` 算真，
  `PORTPROMPT:`/`nul:`/`FILE:`/`XPS`/`*.pdf` 算假。
- 如果一台都没列出来，说明本机确实没有真实打印机，先装驱动。

## 打印没反应 / 卡在队列里

- 看 `runtime/server.log`，里面有每一步的记录
- 检查打印机是否脱机、缺纸、卡纸、墨盒没墨
- Windows 打印队列里有卡住的旧任务：控制面板 → 设备和打印机 → 看队列 → 取消所有文档
- 跑 `python selftest.py` 确认链路本身没问题

## 打出来太小 / 边距太大

通常是**双重边距**：PDF 自己带白边，又被缩了一次。
勾上 **「重排放大」**（先剥白边再等比放大到设定的边距框）。详见 [04](04-排版与打印参数.md)。

## 打出来糊

- 检查质量档位，草稿 200dpi 会很糊，用标准 300 或精细 360
- 原图本身像素不够：微信缓存缩略图放到 A4 满幅必然糊，
  看列表里的**清晰度标签**，偏软的就选 A5/A6/4R
- Office 文档走"原格式直印"比转 PDF 再打清晰

## Word / Excel / PPT 打印报错

- 本机装了 Office 吗？WPS 的 COM 接口不完全兼容，可能出现诡异错误
- Office 弹窗卡住了：打印时 Office 进程是隐藏的，如果它弹出对话框就会一直等。
  手动打开一次那个文件看它是否要求修复/转换
- 不想装 Office：改用位图通道（不选"原格式直印"），程序会尝试转 PDF 再渲染，
  代价是边距由页面设置决定

## 微信文件列表是空的

- 电脑版微信**必须登录并运行**
- 确认微信确实收到过文件（`msg/file/YYYY-MM/` 下有东西）
- 点一次刷新，等 1-2 秒
- 用「文件传输助手」最稳：手机上转发到文件传输助手，电脑上立刻能扫到

## 微信图片列表是空的 / 图很糊

- 空：这台机器上微信没有生成明文缓存图。发几张图、或者收藏几张再试
- 糊：能取到的是**明文缓存版本**，不是原图。要高清就把图片**以文件形式**发送，
  它就会落到 `msg/file/` 下，和文件一样完整。原理见 [03](03-微信文件与图片.md)

## 端口 8760 被占用

服务会自动往后试 8761…8765，窗口里显示的是实际端口，按那个访问就行。
想固定端口：

```bash
set PRINTSERVER_PORT=9000
python server.py
```

## 改了代码不生效

服务不热重载，必须重启。而且要确认你访问的是**新起的那个进程** ——
如果旧进程还占着端口，新进程会检测到并自动退出（这是刻意设计的，
避免两个进程抢同一个端口导致请求被随机分发）。先关掉旧的黑色窗口。

## 上传大文件失败

单个文件上限 200MB。超了就在电脑上直接打，或者先压缩/拆分页。

## 会不会泄露文件

不会。服务不联网上传任何内容，只在局域网内工作，防火墙规则限制 `remoteip=localsubnet`。
微信那部分只读不写，见 [03](03-微信文件与图片.md)。
