# 手机端安装与配置

先分清两件事，因为它们的安装方式完全不同：

| | 是什么 | 要不要装 APP |
| --- | --- | --- |
| **打印网页** | 手机上选文件、排版、点打印的那个界面 | **不用装**，浏览器打开网址即可 |
| **打印中转 APP** | 让微信 / 相册 / WPS 的「分享」列表里出现一个中转选项 | **要装 APK** |

只用「手机上传文件打印」的话，**只看第一章就够了**，APP 属于可选增强。

---

## 一、打印网页：30 秒搞定（不用装任何东西）

### 1. 电脑上启动服务

双击 `启动打印助手.bat`（便携版）或运行 `python server.py`（源码版）。
命令行窗口里会显示类似这样的一行：

```
手机访问: http://192.168.1.23:8760
```

> 这个 `192.168.x.x` 是电脑在局域网里的地址，每台机器不一样，以你窗口里显示的为准。

### 2. 手机连同一个 WiFi

手机和电脑必须**在同一个局域网**（同一个 WiFi）。用手机流量、或者连了访客网络都不行。

### 3. 手机浏览器打开那个地址

- **必须用系统浏览器**（Chrome、Edge、三星浏览器、小米自带浏览器等）
- **不要用微信内置浏览器打开**——微信的浏览器对文件选择有限制，图片能选但文档类经常取不到

打开后就是打印主界面。

### 4. 加到手机桌面（强烈建议）

加完就是一个图标，点开即用，跟 APP 没区别。

**安卓 Chrome**：右上角 `⋮` → 「添加到主屏幕」→ 确认
**安卓 Edge**：右下角 `···` → 「添加到手机」
**iPhone Safari**：底部分享按钮 → 下滑找到「添加到主屏幕」→ 右上角「添加」

### 5. 打不开？按顺序排查

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 一直在转圈 / 无法访问 | 电脑防火墙拦了 | 以管理员身份运行 `setup.py`，会加一条放行规则 |
| 能打开但一直连不上 | 不在同一 WiFi | 手机关掉流量、确认和电脑同一个 SSID |
| 昨天能开今天开不了 | 电脑 IP 变了（DHCP） | 重新看电脑窗口里显示的新地址；建议在路由器里给电脑做「MAC 地址绑定」，IP 就固定了 |
| 电脑睡眠后再也打不开 | 网卡休眠 / 服务被挂起 | 电源设置里把「睡眠」改成「从不」，或唤醒后重启一次服务 |

> 想彻底省心：路由器后台把电脑的 MAC 和 IP 绑定，之后手机收藏夹里的网址就永久有效。

## 二、打印中转 APP：三种路线

APP 的作用只有一个：**当你在微信、相册、WPS 里点「分享」时，列表里出现「打印中转」**，点它就把文件送到电脑打印。

### 路线 A：GitHub 云端编译（推荐，不用装 Android Studio）

Android Studio 要下载 1.5GB 的 SDK，为了 5 个 Java 文件装它不划算。项目里已经配好了自动化：代码推到 GitHub，云端自动编译出 APK。

**步骤：**

1. 把代码推到 GitHub（没推过的话见 [08-发布到GitHub](08-发布到GitHub.md)）
2. 打一个 tag 并推送，触发自动编译：

   ```bash
   git tag v1.0.0
   git push origin v1.0.0
   ```

3. 等 3~5 分钟，打开仓库的 **Actions** 页，能看到「构建安卓中转 APK」跑完变绿
4. 打开 **Releases** 页，附件里就有 `app-debug.apk`
5. **用手机浏览器打开这个 Release 页面，点 apk 下载**（约 100KB，很小）

> 不想打 tag 也行：Actions 页 → 左侧选「构建安卓中转 APK」→ 右上角 `Run workflow` → 跑完在页面底部的 Artifacts 里下载（需要登录 GitHub）。

### 路线 B：本地装 Android Studio 编译（没有 GitHub 时用）

1. 下载安装 [Android Studio](https://developer.android.com/studio)（约 1.5GB，安装时一路默认）
2. 打开 Android Studio → `File → Open` → 选项目里的 **`android-relay`** 文件夹（注意是子目录，不是项目根目录）
3. 第一次会自动下载 Gradle 和 SDK，等进度条走完（首次约 10 分钟）
4. 菜单 `Build → Build Bundle(s) / APK(s) → Build APK(s)`
5. 右下角弹窗点 `locate`，找到 `app-debug.apk`
6. 用微信/QQ 传给自己，或用 USB 拷到手机

### 路线 C：不装 APP 也能用（替代方案）

如果你暂时不想折腾 APK，这两条路同样能把微信里的文件打到打印机：

- **微信文件传输助手**：在微信里把文件发给自己 / 文件传输助手 → 手机网页点「微信文件」→ 直接就能看到并打印。**这条路不需要 APP。**
- **手机网页直接选文件**：网页「选择文件」按钮，从手机存储里选。

唯一区别：APP 是"在任何 APP 里点分享就能送过去"，不用切到打印网页。

## 三、把 APK 装到手机上

### 1. 安装前先授权「允许安装未知应用」

Android 8 以后是按**来源**授权的，也就是说：你用哪个 APP 下载的 APK，就要给哪个 APP 开权限。

| 品牌 | 入口 |
| --- | --- |
| 小米 / Redmi | 设置 → 隐私保护 → 特殊权限设置 → 安装未知应用 → 选你的浏览器 → 允许 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装未知应用；若装不上，**关闭「纯净模式」/「增强防护」** |
| OPPO / realme | 设置 → 权限与隐私 → 安装未知应用 → 选浏览器 → 允许 |
| vivo / iQOO | 设置 → 应用与权限 → 权限管理 → 安装未知应用 → 选浏览器 → 允许 |
| 三星 | 设置 → 应用程序 → 右上角 ⋮ → 特殊访问 → 安装未知应用 |
| 原生 Android /  Pixel | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |

装的过程中如果系统弹「是否允许来自此来源的应用」，直接点允许即可。

### 2. 常见报错

| 报错 | 原因 | 解决 |
| --- | --- | --- |
| 「无法解析安装包」 | 下载不完整，或手机系统版本太低 | 重新下载；本项目要求 Android 5.0 以上（2015 年后的机器都满足） |
| 「安装包与已装应用冲突」 | 之前装过同名 APP | 先卸载旧的再装 |
| 被手机管家拦截 | 安全软件把未签名 APK 当风险 | 点「继续安装 / 忽略风险」，代码全部开源可自行核对 |
| 装完找不到图标 | 桌面抽屉里 | 在应用列表里找「打印中转」 |

## 四、首次配置 APP（关键一步）

装完打开「打印中转」，界面只有两件事：

1. **电脑地址**：填 `http://192.168.x.x:8760`（就是第一章电脑窗口里显示的那个，**末尾不要加斜杠**）
2. 点「保存并测试」——显示成功就说明手机已经能找到电脑了

> 前提：电脑上的打印服务正在运行。**这次一定要重启一次服务**（旧版本还没加载收件箱接口）。

### 试一下整条链路

1. 在微信里随便找一个文件（或一张图片）→ 长按 → 「发送给朋友」/「分享」
2. 分享列表里选 **打印中转**
3. 屏幕一闪，提示「已存入收件箱 N 个，已传电脑 N 个」
4. 打开手机上的打印网页 → 点「手机中转」→ 文件就在列表里，带「新」标
5. 勾选 → 加入打印队列 → 打印

列表**每 4 秒自动刷新**，不用手动刷。

### 注意事项

- **IP 会变**：路由器 DHCP 重新分配后，APP 里填的地址就失效了，需要重填。建议在路由器里给电脑做 MAC 地址绑定，一劳永逸。
- **只走局域网**：文件不经过外网，断网也能打。
- **存了双份**：APP 同时在手机 `Download/手机打印收件箱/` 里留了一份。就算电脑没开，之后也能从网页的「选择文件」里手动选到，不会丢。
- **微信里直接发的图片**：微信对聊天图片做了加密存储，任何第三方都读不到原图。要打图片，请在微信里用「发送文件」的方式发（而不是直接在聊天框发图），或者走相册分享。

## 五、验收清单

- [ ] 手机浏览器能打开打印网页，并已添加到桌面
- [ ] 手机上传一张图片，能出预览、能打印出纸
- [ ] （可选）APK 装好，APP 里测试连接成功
- [ ] （可选）微信分享 → 打印中转 → 网页「手机中转」里出现该文件
- [ ] 电脑 IP 已做 MAC 绑定（可选但强烈建议）
