# 02 · 源码部署

适合要改代码、跑最新版本的人。只想直接用请看 [01-快速开始](01-快速开始.md) 的便携版。

## 1. 环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11（依赖 pywin32、GDI、Office COM） |
| Python | 3.10 ~ 3.13（推荐 3.13，与便携版一致） |
| 打印机 | 已安装驱动且本机可打印 |
| 可选 | Microsoft Office（要用"原格式直印"Word/Excel/PPT 时） |

> 用虚拟环境的话注意：**pywin32 装完必须执行一次 `python Scripts/pywin32_postinstall.py`**，
> 否则 `import win32print` 会失败。系统 Python 直接装的通常会自动完成。

## 2. 安装依赖

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

装不上或者很慢：

```bash
pip install -r requirements.txt -i https://pypi.org/simple
```

> 国内镜像有时索引不全（例如某些包在清华源上找不到版本），官方源实测反而更快更全。

## 3. 启动

```bash
python server.py
```

- 默认端口 **8760**，被占用会自动往后试到 **8765**
- 也可以用环境变量指定：`set PRINTSERVER_PORT=9000 && python server.py`
- 启动后日志会打印局域网 IP，同时写进 `runtime/server.log`

如果端口上已经有一个本服务在跑，新进程会**主动退出**而不是抢端口——
Windows 上 `SO_REUSEADDR` 允许两个进程绑同一端口，请求会被随机分给其中一个，
表现出来就是"功能时灵时不灵"。所以开跑前会先探一次 `/health`。

## 4. 开机自启 + 防火墙

用**管理员权限**跑一次：

```bash
首次安装并启动.bat
```

它等价于 `python setup.py`，做三件事：

1. 防火墙放行 TCP 8760-8765，且限制 `remoteip=localsubnet`（只允许局域网，不外泄）
2. 在「启动」文件夹里放一个快捷方式，开机自动用 `pythonw.exe` 后台跑
3. 立刻启动一次服务

卸载自启：

```bash
停止打印服务.bat
```

手动删除防火墙规则：

```bash
netsh advfirewall firewall delete rule name="手机打印服务"
```

## 5. 自检

```bash
python selftest.py
```

不消耗任何纸张，在内存里验证：

1. 每种纸张 + 横竖方向能否正确建立打印 DC
2. DIB 位图打包是否正常
3. 能否把图像真正画进 DC（用内存 DC 代替打印机）
4. `win32ui` CDC 包装是否可用
5. Canvas 计算 + 排版在 A4/A5/4R、fit/fill/natural 各种组合下是否都产出正确尺寸
6. 作业创建与删除的生命周期

任何一项 `[FAIL]` 都会让退出码变成 1。

## 6. 目录里会多出什么

```
runtime/
├── jobs/        上传的作业（按 job id 分目录）
├── server.log   运行日志
└── config.json  记住的打印机选择
```

这些都在 `.gitignore` 里，不会被提交。清空 `runtime/` 不影响程序功能。

## 7. 停止 / 重启

- 前台跑的：Ctrl+C
- 后台跑的：任务管理器里结束 `pythonw.exe`，或 `taskkill /f /im pythonw.exe`
- 改完代码要重启才生效（服务不热重载）
