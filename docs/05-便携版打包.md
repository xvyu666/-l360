# 05 · 打包便携版（免装 Python 的绿色版）

目标：产出一个文件夹，拷到任何一台 Windows 电脑上，**双击 bat 就能用**。
不装 Python、不联网、不写注册表。

## 1. 原理

不是 PyInstaller，是"**嵌入式 Python + 手工搬运依赖**"：

```
官方 python-3.13.x-embed-amd64.zip  （10MB，官方发布的免安装版）
        + 真正用到的几个包（PIL / pypdfium2 / win32 / pillow_heif …）
        + 本项目源码
        + 一个 .bat
= dist/手机打印助手/
```

好处是体积可控（约 80MB）、启动快、没有 PyInstaller 那种杀软误报；
代价是要自己处理 pywin32 的几个坑（下面第 4 节）。

## 2. 步骤

```bash
# ① 装好依赖（用系统 Python 或 venv 都行）
pip install -r requirements.txt

# ② 下载嵌入式 Python（10MB）
python tools/fetch_pyembed.py            # 默认 3.13.14
#   或指定版本：python tools/fetch_pyembed.py 3.12.10
#   也可以手动下载后放到 runtime/pyembed.zip

# ③ 打包
python build_portable.py
```

产物：

```
dist/手机打印助手/
├── 启动打印助手.bat
├── 排错模式.bat          # 内容一样，留给"想看报错"的场景
├── 使用说明.txt
├── runtime/              # 免装 Python + 依赖
│   ├── python.exe
│   ├── python313.zip     # 标准库
│   └── Lib/site-packages/
└── app/                  # 源码 + 页面
    ├── server.py …
    └── web/
```

## 3. 分发

把 `dist/手机打印助手/` 整个打成 zip：

```bash
# 名字带上版本号
手机打印助手-v1.0-便携版.zip
```

上传到 GitHub Release（见 [08-发布到GitHub](08-发布到GitHub.md)）。
**不要**把它提交进 Git —— 80MB 会让仓库 clone 变慢，而且接近 GitHub 的配额。

## 4. 踩过的坑（改代码时务必注意）

这几个是实测踩出来的，改动 `build_portable.py` 时别回退回去：

**① `._pth` 里必须保留标准库 zip**
嵌入式 Python 把整个标准库打包在 `python313.zip` 里。
`._pth` 漏了这一行，启动时连 `encodings` 都 import 不到，直接崩溃。
最终写进去的内容是：

```
python313.zip
.
..\app
Lib\site-packages
import site
```

**② pywin32 有两个"伪装成 DLL 的扩展模块"**
Python 只认 `.pyd` 后缀，而 pywin32 把 `pythoncom313.dll` 放在 `pywin32_system32/`、
`win32ui.pyd` 放在 `pythonwin/`。照搬过去 import 不到，必须改名并挪到 site-packages：

```
pywin32_system32/pythoncom313.dll  →  site-packages/pythoncom.pyd
pythonwin/win32ui.pyd              →  site-packages/win32ui.pyd
```

**③ 只复制 `win32/` 目录不够**
还需要 `pywin32.pth`（负责把 `win32`、`win32\lib`、`pythonwin` 挂进 `sys.path`），
以及它最后那行 `import pywin32_bootstrap`（在 `win32\lib\` 下，随 win32 目录一起过去）。
少了就是满屏 `No module named 'win32print'`。

**④ 根目录的 `.pyd` / `.dll` 要一起带走**
`pillow_heif` 依赖 libheif 系列 DLL，漏了 iPhone 的 HEIC 照片就打不开。

**⑤ 用 `python.exe` 而不是 `pythonw.exe`**
这个窗口要一直留着显示网址，换成无窗口版本用户就不知道让手机访问哪个地址了。

**⑥ 删目录用 `shutil.rmtree`**
本机 shell 的 `rm` 会走安全 shim 报错，别用 shell 删。

## 5. 体积

| 部分 | 大约 |
| --- | --- |
| 嵌入式 Python | 11 MB |
| 依赖（PIL + pypdfium2 + pywin32 + libheif） | 65 MB |
| 源码 + 页面 | 3 MB |
| **合计** | **约 80 MB** |

想瘦身的话：`pypdfium2` 是大头（PDF 渲染必需，去不掉）；
`pillow_heif` + libheif 约 10MB，不打 HEIC 可以去掉（`build_portable.py` 的 `NEED_PKG` 里删掉即可）。

## 6. 换电脑的验证清单

拷到新机器后确认这四件事：

1. 双击 bat，黑窗口出现且显示网址
2. 手机能打开那个网址
3. 页面顶部能看到目标打印机（不是空的、也不是虚拟 PDF 打印机）
4. 点「打印测试页」，出纸

第 3 条最容易出问题：新电脑如果没装打印机驱动，`list_printers()` 会返回空。
程序按**端口**判断真假打印机（`USB001`/`LPT`/`COM`/`IP_`/`WSD` 为真；
`PORTPROMPT:`/`nul:`/`FILE:`/`XPS`/`*.pdf` 为假），比按名字猜准得多。
